# TAT loan-cycle language

This complements the repository's domain glossary in AGENTS.md.

## Language

**BM analysis approval**:
The Branch Manager's decision after an officer sends M-PESA information and
before the Admin verifies and forwards it. Approval permits the next step;
decline ends the case.
_Avoid_: BM response to CA, credit assessment

# Origination language

**Completed application**:
An application whose required details and documents are finished without
e-signing. Completion is not loan approval or evidence of a signature.
_Avoid_: Approved application, signed application

**Application copy**:
One PDF containing all selected application documents, or an individual document
from that application. Downloading a copy is not review, signing or approval.
