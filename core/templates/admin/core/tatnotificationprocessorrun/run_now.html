How to test escalation safely

  1. Use a Pilot TAT group and assign a primary plus at least one backup in its responsibility roster.
  2. Confirm the backup has matching TAT access and connected private alerts.
  3. For an immediate soft-escalation test, disconnect the primary's private alerts, then create or advance a Pilot case to that role's stage.
  4. For a time-threshold test, use a short Pilot stage target and backup threshold, wait until the recipient is due, then return here.
  5. Run the processor and verify the private message plus the recipient delivery states on the TAT action task. Reconnect the primary after testing.

No public TAT group exception message is sent. Do not alter Production case timestamps to make a test due.
